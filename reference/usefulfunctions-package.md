# usefulfunctions: Reusable Helpers for Single-Cell, Bulk RNA-Seq and Cancer Genomics

Helper functions for immunology and cancer-genomics analyses: colour
palettes, differential-expression volcano plots, heatmaps and
dendrograms, mouse-human gene-symbol conversion, Gene Ontology
over-representation, TCGA overall-survival analysis stratified by gene
or signature expression, and single-cell (Seurat) helpers such as UMAP
hyper-parameter sweeps and gene-gene correlation. Heavy Bioconductor
dependencies are optional (Suggests) so the package installs quickly;
each function checks for what it needs at call time.
